МОСТ ПЕЧАТИ ДЛЯ КАФЕ

Нужен постоянно включённый компьютер в той же локальной сети, что и принтеры.
Установите Node.js 22 или новее с официального сайта https://nodejs.org/.
На Windows запустите START-WINDOWS.cmd. В остальных системах: npm ci, затем npm start.
При первом запуске вставьте код из
«Сотрудники → Настройки принтера → Подключить компьютер».
Код не пересылайте посторонним. Перевыпуск кода отключает прежний компьютер.

В кабинете задайте адрес/порт кухни и адрес/порт бара. На одном IP нужны разные
порты/шлюз. Два одинаковых IP:порт не являются разными принтерами.
80 мм — ширина растра 576 точек, 58 мм — 384 точки. Протокол ESC/POS raster.
Настройки другого кассового приложения не подключают этот мост автоматически.

ПРОВЕРКА: рабочие переключатели печати оставьте ВЫКЛЮЧЕННЫМИ.
Кнопки теста печатают только «ТЕСТ ПЕЧАТИ — НЕ ЗАКАЗ» с назначением.
Реальные заказы для проверки использовать не нужно.
«Передано» означает передачу в TCP-соединение. Это не подтверждение бумаги
датчиком принтера. При неопределённом результате автоматического повтора нет.
Компьютеру нужны исходящий HTTPS в Supabase и TCP к указанным локальным IP.
Входящий доступ из интернета и перенаправление портов роутера не требуются.
